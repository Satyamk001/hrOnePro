### LinkedIn
Excited to share **Attendance Insights** — a zero-install attendance analytics layer built for employees using HROne.

Instead of navigating delayed monthly calendar grids or manually calculating daily hours, Attendance Insights provides:
• Real-time intraday punch tracking (`TodayCard`)
• Dynamic departure target calculation ("Can leave at 18:30")
• Cumulative monthly Net Overtime / Shortfall balance
• One-click background headless sync via companion Chrome Extension & Bookmarklet
• 100% client-side privacy with local browser storage

Built with React 19, TypeScript, TailwindCSS, and Framer Motion.
